# 🎨 shadcn/ui Design System & Architecture Specification

이 저장소는 `shadcn/ui` 및 `Tailwind CSS` 기반 개인 프로젝트 개발을 위한 **디자인 시스템 및 프론트엔드 아키텍처 명세서 (`design.md`)**를 관리하는 공간입니다.

## 🛠️ 주요 명세 내용

1. **프로젝트 개요 및 핵심 원칙** (Code Ownership, Accessibility First, Composition over Inheritance 등)
2. **기술 스택 & 아키텍처** (Next.js App Router, Tailwind v4/v3, Radix UI Primitives, Lucide Icons 등)
3. **디자인 토큰 & 테마 시스템** (OKLCH / HSL 기반 Light/Dark 시맨틱 토큰 매핑, Typography, Border Radius, Shadow)
4. **shadcn/ui 컴포넌트 아키텍처** (CVA 패턴, `asChild` Slot 다형성, 30+ 컴포넌트 카탈로그 및 a11y 표준)
5. **레이아웃 & 정보 설계** (Root App Shell, 반응형 Breakpoints 전략, Framer Motion & Skeleton)
6. **상태 관리 & 데이터 흐름** (Server/Client Components 경계선, React Hook Form + Zod 스키마 검증)
7. **개발 표준 & 코딩 컨벤션** (네이밍 규격, `forwardRef` 표준 패치, Git 커밋 컨벤션)
8. **프로젝트 셋업 & 품질 체크리스트** (초기화 CLI 명령어 모음, 7가지 품질 검수 리스트)
